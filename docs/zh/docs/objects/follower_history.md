# Follower history（粉丝数变化）对象

Follower history（粉丝数变化）对象有 6 个字段，由小红书的 1 个接口返回。每次调用 $0.0400。它是预览结构，之后可能调整。

给机器读：[follower_history schema](https://dataxapi.com/openapi.json#/components/schemas/follower_history)、[openapi.json](https://dataxapi.com/openapi.json)、[对象表（JSON）](https://api.dataxapi.com/v1/catalog/objects)、[llms.txt](https://dataxapi.com/zh/llms.txt)

## 字段

平台给不了的字段不会出现在这条数据里，而是写在 `meta.unavailable` 里。不会用猜的数或 0 顶上。

| 字段 | 类型 | 起始档位 | 说明 |
| --- | --- | --- | --- |
| `creator_id` | 文本 | `compact` | 博主编号，就是请求里给的那个 |
| `days` | 整数 | `compact` | 统计的是最近多少天 |
| `gained` | 整数 | `compact` | 这段时间粉丝净增多少，掉粉时为负 |
| `growth` | 数字 | `compact` | 净增占开始时粉丝数的比例：0.01 是涨了 1% |
| `points` | 对象列表 | `compact` | 逐日的粉丝数，一天一项，从早到晚 |
| `points[].date` | 时间 | `compact` | 日期：中国时间（UTC+8）的一个自然日，写成这个日期的 UTC 零点 |
| `points[].followers` | 整数 | `compact` | 这一天的粉丝总数 |
