# Topic（话题）对象

Topic（话题）对象有 6 个字段，由小红书的 1 个接口返回。每次调用 $0.0200。它是预览结构，之后可能调整。

给机器读：[topic schema](https://dataxapi.com/openapi.json#/components/schemas/topic)、[openapi.json](https://dataxapi.com/openapi.json)、[对象表（JSON）](https://api.dataxapi.com/v1/catalog/objects)、[llms.txt](https://dataxapi.com/zh/llms.txt)

话题（Topic）是把同一个标签或主题下的内容聚在一起的那个页面，带名称、简介和浏览数。现在来自小红书的话题页，`ext.discussions` 是页面上显示的讨论数。

`id` 是 24 位十六进制的话题页编号，可以原样传给取话题下热门笔记的接口，笔记按内容对象返回。热榜上的热点是另一回事：它是榜单上的一条，靠名称认。

## 字段

平台给不了的字段不会出现在这条数据里，而是写在 `meta.unavailable` 里。不会用猜的数或 0 顶上。

| 字段 | 类型 | 起始档位 | 说明 |
| --- | --- | --- | --- |
| `id` | 文本 | `compact` | 编号，可原样传给取话题资料和取话题下内容的接口 |
| `name` | 文本 | `compact` | 话题的名称 |
| `url` | 链接 | `compact` | 能直接打开的链接 |
| `description` | 文本 | `compact` | 话题的简介；没写则为 null |
| `metrics` | 对象 | `compact` | 话题的数字 |
| `metrics.views` | 整数 | `compact` | 话题的浏览数 |
| `metrics.posts` | 整数 | `compact` | 话题下的内容数 |

## 哪些平台给不了哪些字段

一个平台的所有接口都给不了某个字段时，它才列在那个字段后面。

| 字段 | 给不了的平台 |
| --- | --- |
| `metrics.posts` | 小红书 |

同一个平台上，可能一个接口给不了、另一个接口能给：每个接口的页面列着它给不了的字段，每次返回也都写在 `meta.unavailable` 里。
