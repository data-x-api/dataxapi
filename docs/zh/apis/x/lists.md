# X 列表 API（推特列表）

3 个接口读 X 列表：列表帖子、成员、关注者。一次 $0.0004 到 $0.0080。不用登录 X，不用 Cookie；失败不收费。

也叫：X Lists

## 这组数据是什么

**X 列表（Lists）是有人把一批账号收在一个名字下，列表的时间线就是这些账号发的帖子。**这组接口按列表编号读时间线（从新到旧，每页约 100 条）、列表收录的账号和关注这个列表的账号。

帖子按内容对象返回，账号按账号对象返回，和 X 其他接口一样。别人维护好的列表就是现成的关注名单：一次调用就读到里面所有账号发的帖子。

- **时间线**：从新到旧，每页约 100 条，一次调用一个价，不论返回多少条；用 `page.next_cursor` 往前翻更早的帖子。
- **成员和关注者**：成员是列表收录的账号，每页 20 个。关注者是关注了这个列表的账号：最多 20 个，只有一页。
- **列表编号**：一串数字。这里没有搜列表的接口，要从已知的列表开始。

## 一个典型用法，和它的账单

**每天读一个精选列表。**每天一次调用，最多拿到列表里的 100 条帖子；成员读一次。成员按返回的条数计费，所以那一行是最多会花的数。

| 调用 | 次数 | 花费 |
| --- | --- | --- |
| X 列表帖子 | 7 × $0.0020 | $0.0140 |
| X 列表成员 | 1 × $0.0080 (最多) | $0.0080 |
| 合计 8 次调用 |  | 最多 $0.0220 |

## 常见问题

### 多少钱？

按次收费，没有订阅。一次 $0.0004 到 $0.0080，每个接口的页面写明自己的价格。有 2 个接口按返回的条数计费，每次有最低和最高。拿到数据才扣费，失败不收。

### 能读到一个列表的全部关注者吗？

不能，只有前 20 个。实测时平台给的下一页是空的，所以不提供下一页。列表成员可以正常往后翻。

### 列表不存在会怎样？

时间线不会返回 404：按出错返回，可以重试一次，不收费。成员和关注者列表返回空结果。

### 需要 X 列表或 X 的账号吗？

不需要。你只拿一把 DataXAPI 的 Key：不用登录 X，不用 Cookie，也不用广告主账号。
