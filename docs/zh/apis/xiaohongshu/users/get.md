# 小红书用户资料 API

按用户编号或主页链接取小红书账号资料：昵称、小红书号、简介、粉丝数、关注数、笔记数、是否认证，以及主页显示的性别和自填地区。每次取一个对象；$0.0200 一次。出错、超时、对象不存在都不收费。

- 地址：`GET https://api.dataxapi.com/v1/xiaohongshu/users/get`
- 编号：`xiaohongshu.users.get`
- 也叫：小红书博主资料、小红书账号信息、小红书用户信息、小红书博主信息、小红书作者主页
- 价格：$0.0200 / 次
- 当前状态不写在这一页上（页面是快照），实时读：`GET https://api.dataxapi.com/v1/catalog/status`
- 返回：1 个对象, 一个账号对象
- 返回标准的账号结构，各平台相同
- `id` 就在链接里：`xiaohongshu.com/user/profile/<id>`。也可以把整条链接传给 `url`。
- [在 Playground 里跑一次](https://dataxapi.com/zh/console/playground/?capability=xiaohongshu.users.get&params=%7B%22id%22%3A%2263bed214000000002702b862%22%7D)
- 英文名：[Xiaohongshu user profile API](https://dataxapi.com/apis/xiaohongshu/users/get/)

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | 文本 | `id`、`url` 里给且只给一个 | 用户编号，24 位十六进制。手里只有主页链接时，填到 url。示例：`63bed214000000002702b862`。 |
| `url` | 文本 | `id`、`url` 里给且只给一个 | 用户主页链接，原样粘贴即可：https://www.xiaohongshu.com/user/profile/…（后面带 xsec_token 等参数也行）、含这种链接的整段分享文案，或 App 复制出来的 xhslink.com 短链接。短链接由我们打开一次，看它跳到哪个主页；打不开时请贴完整的主页链接或用户编号。示例：`https://www.xiaohongshu.com/user/profile/63bed214000000002702b862?xsec_token=ABx1y2z3`。长链接：`https://www.xiaohongshu.com/user/profile/63bed214000000002702b862?xsec_token=ABx1y2z3`。带链接的分享文案：`周末咖啡探店合集 https://www.xiaohongshu.com/user/profile/63bed214000000002702b862?xsec_token=ABx1y2z3 复制这段文字，打开小红书查看`。 |
| `view` | 文本 |  | 返回档位。三档价格相同。取值：`compact`、`standard`（默认）、`full`。 |
| `fields` | 文本列表 |  | 只要这些字段。按路径写，例如 `author.name`。 |

## 返回字段

`data.item` 是一个账号对象。稳定：字段只增不改。

返回分三档：精简 `compact`（最常用的字段，长文本截短）、标准 `standard`（默认，全部标准字段）、完整 `full`（再加 `ext`，也就是这个平台特有的字段）。字段从表里写的那一档起出现，更大的档位也带。

| 字段 | 类型 | 说明 | 起始档位 | 这个接口 |
| --- | --- | --- | --- | --- |
| `id` | 文本 | 编号。 | `compact` | 有 |
| `username` | 文本 | 账号名。 | `compact` | 有 |
| `name` | 文本 | 显示名。 | `compact` | 有 |
| `url` | 链接 | 主页链接。 | `compact` | 有 |
| `bio` | 文本 | 简介。长文本：精简档只保留前 500 个字符，并在 `warnings` 里写明。 | `compact` | 有 |
| `avatar_url` | 链接 | 头像。 | `standard` | 有 |
| `verified` | 是否 | 是否认证。 | `standard` | 有 |
| `created_at` | 时间 | 账号创建时间。 | `standard` | 这个接口不提供 |
| `metrics` | 对象 | 账号的数字。 | `compact` | 有 |
| `metrics.followers` | 整数 | 粉丝数。 | `compact` | 有 |
| `metrics.following` | 整数 | 关注数。 | `compact` | 有 |
| `metrics.posts` | 整数 | 发布的内容数。 | `compact` | 有 |
| `ext.ip_location` | 文本 | 平台显示的 IP 属地，给的是英文写法（省份的拼音或英文名），App 里显示的是中文。 | `full` | 有 |
| `ext.likes` | 整数 | 笔记获得的点赞总数。 | `full` | 有 |
| `ext.favorites` | 整数 | 笔记被收藏的总数。 | `full` | 有 |
| `ext.gender` | 文本 | 主页上显示的性别：female 女、male 男；主页没显示为 null。取值：`female`、`male`。 | `full` | 有 |
| `ext.location` | 文本 | 账号自己填的地区，平台的原话（国家、省、市，用空格隔开）；没填为 null。不是 IP 属地。 | `full` | 有 |
| `approximate` | 对象列表 | 这一条里哪些数是约数或下限；都是准确值时不出现。 | `compact` | 有 |
| `approximate[].field` | 文本 | 字段的路径，如 metrics.views。 | `compact` | 有 |
| `approximate[].kind` | 文本 | 约数，还是下限。取值：`approximate`、`lower_bound`。 | `compact` | 有 |

某一条本来就没有这个值时，字段给 `null`。这个接口给不了的字段不出现，统一列在 `meta.unavailable`。

每条数据的典型体积：`compact` 478 B、`standard` 625 B、`full` 723 B（按 2026-10-12 18:43 UTC 录下的那次返回量的）。

## 对象不存在时

返回 404 `not_found`，不收费。`reason` 写明是哪一种：`not_found`（不存在）或 `private_or_deleted`（私密或已删除）。
