# 小红书蒲公英关联词 API

按一个关键词取小红书用户搜它之前和之后还会搜的词（蒲公英），各带相关度名次、搜索指数、相关笔记数和阅读数，用来拓词选题。搜索指数是平台算出的指数，不是搜索次数；平台不给数的词，这几项为 null。每次约 98 条，最多 120 条；$0.0400 一次。出错和超时不收费。

- 地址：`GET https://api.dataxapi.com/v1/xiaohongshu/pgy/keywords/related`
- 编号：`xiaohongshu.pgy.keywords.related`
- 也叫：小红书关联词、小红书上下游词、蒲公英拓词、小红书相关搜索词
- 价格：$0.0400 / 次
- 当前状态不写在这一页上（页面是快照），实时读：`GET https://api.dataxapi.com/v1/catalog/status`
- 返回：每页最多 120 条, 一次给全，不翻页
- 返回关联词，预览结构，以后可能调整
- [在 Playground 里跑一次](https://dataxapi.com/zh/console/playground/?capability=xiaohongshu.pgy.keywords.related&params=%7B%22keyword%22%3A%22%E9%9D%A2%E8%86%9C%22%7D)
- 英文名：[Xiaohongshu PGY related keywords API](https://dataxapi.com/apis/xiaohongshu/pgy/keywords/related/)

## 返回字段

`data.items` 是关联词对象的列表。预览：结构可能调整，改之前会公告。

返回分三档：精简 `compact`（最常用的字段，长文本截短）、标准 `standard`（默认，全部标准字段）、完整 `full`（再加 `ext`，也就是这个平台特有的字段）。字段从表里写的那一档起出现，更大的档位也带。

| 字段 | 类型 | 说明 | 起始档位 | 这个接口 |
| --- | --- | --- | --- | --- |
| `keyword` | 文本 | 关联词。 | `compact` | 有 |
| `related_to` | 文本 | 它是哪个词的关联词：所查的那个关键词。 | `compact` | 有 |
| `relation` | 文本 | 怎么关联的：query 是搜索里一起出现，posts 是内容里一起出现，prior 是人们搜所查的词之前搜的，after 是之后搜的，suggestion 是在搜索框里输入所查的词时平台给的联想词。取值：`query`、`posts`、`prior`、`after`、`suggestion`。 | `compact` | 有 |
| `rank` | 整数 | 在同一种关联里按相关度排第几，从 1 起。 | `compact` | 有 |
| `relevance` | 数字 | 和所查的词的相关度，0 到 1。 | `compact` | 平台没有 |
| `search_index` | 整数 | 这个关联词的搜索指数：平台算出的指数，不是搜索次数；平台不给这个词的数时为 null。 | `compact` | 有 |
| `composite_index` | 整数 | 这个关联词的综合指数：平台把相关内容的热度合起来算出的指数，不是次数。 | `compact` | 平台没有 |
| `ext.notes` | 整数 | 和这个关联词有关的笔记数；平台不给这个词的数时为 null。 | `full` | 有 |
| `ext.views` | 整数 | 这些笔记的阅读总数；平台不给这个词的数时为 null。 | `full` | 有 |
| `approximate` | 对象列表 | 这一条里哪些数是约数或下限；都是准确值时不出现。 | `compact` | 有 |
| `approximate[].field` | 文本 | 字段的路径，如 metrics.views。 | `compact` | 有 |
| `approximate[].kind` | 文本 | 约数，还是下限。取值：`approximate`、`lower_bound`。 | `compact` | 有 |

某一条本来就没有这个值时，字段给 `null`。这个接口给不了的字段不出现，统一列在 `meta.unavailable`。

每条数据的典型体积：`compact` 98 B、`standard` 98 B、`full` 137 B（按 2026-10-12 21:42 UTC 录下的那次返回量的）。
