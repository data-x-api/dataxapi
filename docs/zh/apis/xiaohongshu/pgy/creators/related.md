# 小红书蒲公英相似博主 API

给一个蒲公英博主编号，取蒲公英推荐的和他相似的小红书博主：博主编号、昵称、小红书号、所在地、内容类目、粉丝数，完整档另有报价和阅读、互动中位数。一次 4 位（蒲公英一页就 4 位），通常共几位到几十位，可以翻页。每次最多 4 条；$0.0400 一次。出错和超时不收费。

- 地址：`GET https://api.dataxapi.com/v1/xiaohongshu/pgy/creators/related`
- 编号：`xiaohongshu.pgy.creators.related`
- 也叫：小红书相似博主、蒲公英相似博主推荐、找类似的小红书博主、小红书同类博主
- 价格：$0.0400 / 次
- 当前状态不写在这一页上（页面是快照），实时读：`GET https://api.dataxapi.com/v1/catalog/status`
- 返回：每页 4 条, 一页，带翻下一页的游标
- 返回达人，预览结构，以后可能调整
- [在 Playground 里跑一次](https://dataxapi.com/zh/console/playground/?capability=xiaohongshu.pgy.creators.related&params=%7B%22id%22%3A%225c0017ef6b58b740c92463fb%22%7D)
- 英文名：[Xiaohongshu PGY similar creators API](https://dataxapi.com/apis/xiaohongshu/pgy/creators/related/)

## 参数

| 参数 | 类型 | 必填 | 说明 |

| `cursor` | 文本 |  | 上一页返回的游标。把上一页的 `page.next_cursor` 原样带上。每翻一页按一次调用收费。 |

## 返回字段

`data.items` 是达人对象的列表。预览：结构可能调整，改之前会公告。

返回分三档：精简 `compact`（最常用的字段，长文本截短）、标准 `standard`（默认，全部标准字段）、完整 `full`（再加 `ext`，也就是这个平台特有的字段）。字段从表里写的那一档起出现，更大的档位也带。

| 字段 | 类型 | 说明 | 起始档位 | 这个接口 |
| --- | --- | --- | --- | --- |
| `id` | 文本 | 达人在这个营销市场里的编号。 | `compact` | 有 |
| `account_id` | 文本 | 这位达人的平台账号编号，可传给同平台的账号接口。 | `compact` | 有 |
| `username` | 文本 | 账号名。 | `compact` | 有 |
| `name` | 文本 | 显示名。 | `compact` | 有 |
| `avatar_url` | 链接 | 头像。 | `standard` | 有 |
| `location` | 文本 | 所在地，平台的原话。 | `standard` | 有 |
| `categories` | 文本列表 | 内容类目（一级），平台的原话。 | `compact` | 有 |
| `subcategories` | 文本列表 | 内容类目（二级），平台的原话。 | `standard` | 有 |
| `metrics` | 对象 | 达人的数字。 | `compact` | 有 |
| `metrics.followers` | 整数 | 粉丝数。 | `compact` | 有 |

每条数据的典型体积：`compact` 181 B、`standard` 360 B、`full` 481 B（按 2026-11-07 04:28 UTC 录下的那次返回量的）。

## 翻页

每页 4 条。每页条数由平台决定，不收 `limit`。

取下一页时把 `page.next_cursor` 作为 `cursor` 带上；游标有效期 1 小时。最后一页的 `page.has_more` 是 false。

## 常见问题

### 小红书蒲公英相似博主 API 多少钱？

$0.0400 一次。单次最高扣费 $0.0400。

### 什么情况下不收费？

出错和超时不收费。

### 一次返回多少条？怎么翻页？

每页 4 条。每页条数由平台决定，不收 limit。取下一页时把 page.next_cursor 作为 cursor 带上；游标有效期 1 小时。最后一页的 page.has_more 是 false。

### 对象不存在会怎样？

分不清“没有这个博主”和“这个博主没有相似博主”：两种情况都返回空结果，不返回 404。
