# LinkedIn 公司帖子 API

按公司的账号名或链接取 LinkedIn 公司主页上公开展示的最近帖子（最多 10 条）：编号、链接、正文、发布时间。不带作者和互动数，互动数用帖子详情取；只有这一页，不能往前翻。每次最多 10 条；$0.0020 一次。出错、超时、对象不存在都不收费。

- 地址：`GET https://api.dataxapi.com/v1/linkedin/companies/posts/list`
- 编号：`linkedin.companies.posts.list`
- 也叫：领英公司动态、领英企业帖子、LinkedIn 企业主页动态
- 价格：$0.0020 / 次
- 当前状态不写在这一页上（页面是快照），实时读：`GET https://api.dataxapi.com/v1/catalog/status`
- 返回：每页 10 条, 一次给全，不翻页
- 返回标准的内容结构，各平台相同
- `username` 就在链接里：`linkedin.com/company/<username>`。也可以把整条链接传给 `url`。
- [在 Playground 里跑一次](https://dataxapi.com/zh/console/playground/?capability=linkedin.companies.posts.list&params=%7B%22username%22%3A%22unesco%22%7D)
- 英文名：[LinkedIn company posts API](https://dataxapi.com/apis/linkedin/companies/posts/list/)

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `username` | 文本 | `username`、`url` 里给且只给一个 | 公司的账号名，即公司主页链接里 /company/ 后面那一段。示例：`unesco`。 |
| `url` | 文本 | `username`、`url` 里给且只给一个 | 公司主页链接，linkedin.com/company/账号名 的写法。示例：`https://www.linkedin.com/company/unesco`。长链接：`https://www.linkedin.com/company/unesco`。 |
| `view` | 文本 |  | 返回档位。三档价格相同。取值：`compact`、`standard`（默认）、`full`。 |
| `fields` | 文本列表 |  | 只要这些字段。按路径写，例如 `author.name`。 |

## 返回字段

`data.items` 是内容对象的列表。稳定：字段只增不改。

返回分三档：精简 `compact`（最常用的字段，长文本截短）、标准 `standard`（默认，全部标准字段）、完整 `full`（再加 `ext`，也就是这个平台特有的字段）。字段从表里写的那一档起出现，更大的档位也带。

| 字段 | 类型 | 说明 | 起始档位 | 这个接口 |
| --- | --- | --- | --- | --- |
| `id` | 文本 | 编号，可原样传给取详情的接口。 | `compact` | 有 |
| `url` | 链接 | 能直接打开的链接。 | `compact` | 有 |
| `type` | 文本 | 内容形态。取值：`video`、`image`、`text`、`article`。 | `compact` | 这个接口不提供 |
| `title` | 文本 | 标题。 | `compact` | 这个接口不提供 |
| `text` | 文本 | 正文。长文本：精简档只保留前 500 个字符，并在 `warnings` 里写明。 | `compact` | 有 |
| `lang` | 文本 | 正文的语言。 | `standard` | 这个接口不提供 |
| `published_at` | 时间 | 发布时间。 | `compact` | 有 |

| `metrics.comments` | 整数 | 评论数。 | `compact` | 这个接口不提供 |
| `metrics.shares` | 整数 | 分享数。 | `compact` | 这个接口不提供 |

| `images` | 链接列表 | 图片地址。 | `standard` | 这个接口不提供 |
| `hashtags` | 文本列表 | 话题标签，不带 #。 | `standard` | 这个接口不提供 |
| `mentions` | 对象列表 | 正文里提及的账号。 | `standard` | 这个接口不提供 |
| `mentions[].id` | 文本 | 账号编号。 | `standard` | 这个接口不提供 |
| `mentions[].username` | 文本 | 账号名。 | `standard` | 这个接口不提供 |
| `mentions[].name` | 文本 | 显示名。 | `standard` | 这个接口不提供 |

每条数据的典型体积：`compact` 637 B、`standard` 799 B、`full` 799 B（按 2026-10-12 19:17 UTC 录下的那次返回量的）。

## 对象不存在时

返回 404 `not_found`，不收费。`reason` 写明是哪一种：`not_found`（不存在）或 `private_or_deleted`（私密或已删除）。

```bash
curl -G "https://api.dataxapi.com/v1/linkedin/companies/posts/list" \
```

```python
# pip install dataxapi
```

## 常见问题

### LinkedIn 公司帖子 API 多少钱？

$0.0020 一次。单次最高扣费 $0.0020。

### 什么情况下不收费？

出错、超时、对象不存在都不收费。

### 一次返回多少条？怎么翻页？

每页 10 条。每页条数由平台决定，不收 limit。一次给全，不发游标。

### 对象不存在会怎样？

返回 404 not_found，不收费。reason 写明是哪一种：not_found（不存在）或 private_or_deleted（私密或已删除）。
