# Facebook 主页资料 API

按主页的账号名、编号或链接取 Facebook 公共主页资料：名称、简介、粉丝数、点赞数、类别、网站、创建日期，以及它在 Meta 广告库里的编号（查它投的广告要用）。每次取一个对象；$0.0020 一次。出错、超时、对象不存在都不收费。

- 地址：`GET https://api.dataxapi.com/v1/facebook/pages/get`
- 编号：`facebook.pages.get`
- 也叫：脸书主页信息、Facebook 公共主页、Facebook 粉丝专页资料
- 价格：$0.0020 / 次
- 当前状态不写在这一页上（页面是快照），实时读：`GET https://api.dataxapi.com/v1/catalog/status`
- 返回：1 个对象, 一个账号对象
- 返回标准的账号结构，各平台相同
- `username` 就在链接里：`facebook.com/<username>`。也可以把整条链接传给 `url`。
- [在 Playground 里跑一次](https://dataxapi.com/zh/console/playground/?capability=facebook.pages.get&params=%7B%22id%22%3A%22100044561550831%22%7D)
- 英文名：[Facebook page profile API](https://dataxapi.com/apis/facebook/pages/get/)

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | 文本 | `id`、`username`、`url` 里给且只给一个 | 主页编号，一串数字。示例：`100044561550831`。 |
| `username` | 文本 | `id`、`username`、`url` 里给且只给一个 | 主页的账号名，即主页链接里 facebook.com/ 后面那一段。示例：`NASA`。 |
| `url` | 文本 | `id`、`username`、`url` 里给且只给一个 | 主页链接，facebook.com/账号名 的写法。示例：`https://www.facebook.com/NASA`。长链接：`https://www.facebook.com/NASA`。 |
| `view` | 文本 |  | 返回档位。三档价格相同。取值：`compact`、`standard`（默认）、`full`。 |
| `fields` | 文本列表 |  | 只要这些字段。按路径写，例如 `author.name`。 |

## 返回字段

`data.item` 是一个账号对象。稳定：字段只增不改。

返回分三档：精简 `compact`（最常用的字段，长文本截短）、标准 `standard`（默认，全部标准字段）、完整 `full`（再加 `ext`，也就是这个平台特有的字段）。字段从表里写的那一档起出现，更大的档位也带。

| 字段 | 类型 | 说明 | 起始档位 | 这个接口 |
| --- | --- | --- | --- | --- |
| `id` | 文本 | 编号。 | `compact` | 有 |
| `username` | 文本 | 账号名。 | `compact` | 有 |
| `name` | 文本 | 显示名。 | `compact` | 有 |
| `url` | 链接 | 主页链接。 | `compact` | 有 |
| `bio` | 文本 | 简介。长文本：精简档只保留前 500 个字符，并在 `warnings` 里写明。 | `compact` | 有 |
| `avatar_url` | 链接 | 头像。 | `standard` | 有 |
| `verified` | 是否 | 是否认证。 | `standard` | 这个接口不提供 |
| `created_at` | 时间 | 账号创建时间。在这个平台上：主页创建的日期，只到天。 | `standard` | 有 |
| `metrics` | 对象 | 账号的数字。 | `compact` | 有 |
| `metrics.followers` | 整数 | 粉丝数。在这个平台上：关注主页的人数，平台从一千起只给约数。 | `compact` | 有 |
| `metrics.following` | 整数 | 关注数。 | `compact` | 平台没有 |
| `metrics.posts` | 整数 | 发布的内容数。 | `compact` | 这个接口不提供 |
| `ext.likes` | 整数 | 给主页点赞的人数。 | `full` | 有 |
| `ext.talking_about` | 整数 | 正在谈论这个主页的人数。 | `full` | 有 |
| `ext.category` | 文本 | 主页的类别，按平台显示的原文。 | `full` | 有 |
| `ext.website` | 链接 | 主页填写的网站。 | `full` | 有 |
| `ext.ad_library_id` | 文本 | 这个主页在 Meta 广告库里的编号，和主页的 id 不是同一个数；查它投的广告（meta.advertisers.ads.list）要的就是这个编号。 | `full` | 有 |
| `approximate` | 对象列表 | 这一条里哪些数是约数或下限；都是准确值时不出现。 | `compact` | 有 |
| `approximate[].field` | 文本 | 字段的路径，如 metrics.views。 | `compact` | 有 |
| `approximate[].kind` | 文本 | 约数，还是下限。取值：`approximate`、`lower_bound`。 | `compact` | 有 |

某一条本来就没有这个值时，字段给 `null`。这个接口给不了的字段不出现，统一列在 `meta.unavailable`。

每条数据的典型体积：`compact` 339 B、`standard` 822 B、`full` 980 B（按 2026-10-12 18:50 UTC 录下的那次返回量的）。

## 对象不存在时

返回 404 `not_found`，不收费。`reason` 写明是哪一种：`not_found`（不存在）或 `private_or_deleted`（私密或已删除）。
