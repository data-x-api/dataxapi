# 抖音高点赞率榜 API

这是 抖音视频榜 API 带 `board=high_like` 的用法。取抖音最近一天的视频榜：低粉爆款、高点赞率、高完播率或高涨粉率，带播放数、点赞数、作者粉丝数。每次约 9 条，最多 10 条；$0.0020 一次。出错和超时不收费。

- 地址：`GET https://api.dataxapi.com/v1/douyin/videos/trending`
- 编号：`douyin.videos.trending`
- 所属接口：[抖音视频榜 API](https://dataxapi.com/zh/apis/douyin/videos/trending/), `board=high_like`
- 价格：$0.0020 / 次
- 当前状态不写在这一页上（页面是快照），实时读：`GET https://api.dataxapi.com/v1/catalog/status`
- 返回：每页最多 10 条, 一页，带翻下一页的游标
- 返回标准的内容结构，各平台相同
- [在 Playground 里跑一次](https://dataxapi.com/zh/console/playground/?capability=douyin.videos.trending&params=%7B%22board%22%3A%22high_like%22%7D)
- 英文名：[Douyin high-like-rate ranking API](https://dataxapi.com/apis/douyin/videos/trending/high_like/)

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `board` | 文本 |  | 这一页固定为 `board=high_like`。选哪个榜：低粉爆款、高点赞率、高完播率、高涨粉率。取值：`low_fan`（默认）、`high_like`、`high_completion`、`high_follow`。示例：`high_like`。 |
| `cursor` | 文本 |  | 上一页返回的游标。把上一页的 `page.next_cursor` 原样带上。每翻一页按一次调用收费。 |
| `view` | 文本 |  | 返回档位。三档价格相同。取值：`compact`、`standard`（默认）、`full`。 |
| `fields` | 文本列表 |  | 只要这些字段。按路径写，例如 `author.name`。 |

## 返回字段

`data.items` 是内容对象的列表。稳定：字段只增不改。

返回分三档：精简 `compact`（最常用的字段，长文本截短）、标准 `standard`（默认，全部标准字段）、完整 `full`（再加 `ext`，也就是这个平台特有的字段）。字段从表里写的那一档起出现，更大的档位也带。

## 翻页

每页约 9 条，最多 10 条。每页条数由平台决定，不收 `limit`。

取下一页时把 `page.next_cursor` 作为 `cursor` 带上；游标有效期 1 小时。最后一页的 `page.has_more` 是 false。

结果来自共享快照，每 10 分钟更新一次；`meta.cached` 会标明，`meta.fetched_at` 是取数时间。

## 请求

代码里的 Key 从环境变量读，不把真 Key 写进页面。

### cURL

```bash
curl -G "https://api.dataxapi.com/v1/douyin/videos/trending" \
  --data-urlencode "board=high_like" \
  -H "Authorization: Bearer $DATAXAPI_API_KEY"
```

### Python

```python
# pip install dataxapi
from dataxapi import DataXAPI

dx = DataXAPI()  # reads DATAXAPI_API_KEY
result = dx.douyin.videos.trending(board="high_like")
print(result["data"]["items"])
```

### TypeScript

```typescript
// npm i @dataxapi/sdk
import { DataXAPI } from "@dataxapi/sdk";

const dx = new DataXAPI(); // reads DATAXAPI_API_KEY
const result = await dx.douyin.videos.trending({ board: "high_like" });
console.log(result.data.items);
```

### 命令行

```bash
dataxapi call douyin.videos.trending board=high_like
```

每页约 9 条，最多 10 条。每页条数由平台决定，不收 limit。取下一页时把 page.next_cursor 作为 cursor 带上；游标有效期 1 小时。最后一页的 page.has_more 是 false。
