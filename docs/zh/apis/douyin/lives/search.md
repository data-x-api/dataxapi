# 抖音直播搜索 API

按抖音号或昵称找主播，看此刻是否在直播：账号编号、抖音号、昵称、头像、粉丝数、是否在播，在播的给直播的房间编号和标题。按内容词（如“游戏”）一般搜不到。每次最多 10 条；$0.0200 一次。出错和超时不收费。

- 地址：`GET https://api.dataxapi.com/v1/douyin/lives/search`
- 编号：`douyin.lives.search`
- 也叫：抖音搜主播、抖音主播是否在直播、抖音主播开播状态、抖音直播房间号
- 价格：$0.0200 / 次
- 当前状态不写在这一页上（页面是快照），实时读：`GET https://api.dataxapi.com/v1/catalog/status`
- 返回：每页 10 条, 一页，带翻下一页的游标
- 返回标准的账号结构，各平台相同
- [在 Playground 里跑一次](https://dataxapi.com/zh/console/playground/?capability=douyin.lives.search&params=%7B%22query%22%3A%22%E4%B8%9C%E6%96%B9%E7%94%84%E9%80%89%22%7D)
- 英文名：[Douyin live search API](https://dataxapi.com/apis/douyin/lives/search/)

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `query` | 文本 | 是 | 主播的抖音号或昵称。示例：`东方甄选`。 |
| `cursor` | 文本 |  | 上一页返回的游标。把上一页的 `page.next_cursor` 原样带上。每翻一页按一次调用收费。 |
| `view` | 文本 |  | 返回档位。三档价格相同。取值：`compact`、`standard`（默认）、`full`。 |
| `fields` | 文本列表 |  | 只要这些字段。按路径写，例如 `author.name`。 |

## 返回字段

`data.items` 是账号对象的列表。稳定：字段只增不改。

返回分三档：精简 `compact`（最常用的字段，长文本截短）、标准 `standard`（默认，全部标准字段）、完整 `full`（再加 `ext`，也就是这个平台特有的字段）。字段从表里写的那一档起出现，更大的档位也带。

| 字段 | 类型 | 说明 | 起始档位 | 这个接口 |
| --- | --- | --- | --- | --- |
| `id` | 文本 | 编号。 | `compact` | 有 |
| `username` | 文本 | 账号名。 | `compact` | 有 |
| `name` | 文本 | 显示名。 | `compact` | 有 |
| `url` | 链接 | 主页链接。 | `compact` | 有 |
| `bio` | 文本 | 简介。长文本：精简档只保留前 500 个字符，并在 `warnings` 里写明。 | `compact` | 这个接口不提供 |
| `avatar_url` | 链接 | 头像。 | `standard` | 有 |
| `verified` | 是否 | 是否认证。 | `standard` | 这个接口不提供 |
| `created_at` | 时间 | 账号创建时间。 | `standard` | 平台没有 |
| `metrics` | 对象 | 账号的数字。 | `compact` | 有 |
| `metrics.followers` | 整数 | 粉丝数。 | `compact` | 有 |
| `metrics.following` | 整数 | 关注数。 | `compact` | 这个接口不提供 |
| `metrics.posts` | 整数 | 发布的内容数。 | `compact` | 这个接口不提供 |
| `ext.is_live` | 是否 | 取数时是否正在直播。 | `full` | 有 |
| `ext.live_room_id` | 文本 | 正在直播时的直播间编号；没在直播时为 null。 | `full` | 有 |
| `ext.live_title` | 文本 | 正在直播时直播间的标题；没在直播时为 null。 | `full` | 有 |
| `approximate` | 对象列表 | 这一条里哪些数是约数或下限；都是准确值时不出现。 | `compact` | 有 |
| `approximate[].field` | 文本 | 字段的路径，如 metrics.views。 | `compact` | 有 |
| `approximate[].kind` | 文本 | 约数，还是下限。取值：`approximate`、`lower_bound`。 | `compact` | 有 |

某一条本来就没有这个值时，字段给 `null`。这个接口给不了的字段不出现，统一列在 `meta.unavailable`。

每条数据的典型体积：`compact` 275 B、`standard` 415 B、`full` 532 B（按 2026-11-28 04:12 UTC 录下的那次返回量的）。

## 翻页

每页 10 条。每页条数由平台决定，不收 `limit`。

取下一页时把 `page.next_cursor` 作为 `cursor` 带上；游标有效期 1 小时。最后一页的 `page.has_more` 是 false。

结果来自共享快照，每 5 分钟更新一次；`meta.cached` 会标明，`meta.fetched_at` 是取数时间。

## 请求

代码里的 Key 从环境变量读，不把真 Key 写进页面。

### cURL

```bash
curl -G "https://api.dataxapi.com/v1/douyin/lives/search" \
  --data-urlencode "query=东方甄选" \
  -H "Authorization: Bearer $DATAXAPI_API_KEY"
```

### Python

```python
# pip install dataxapi
from dataxapi import DataXAPI

dx = DataXAPI()  # reads DATAXAPI_API_KEY
result = dx.douyin.lives.search(query="东方甄选")
print(result["data"]["items"])
```

### TypeScript

```typescript
// npm i @dataxapi/sdk
import { DataXAPI } from "@dataxapi/sdk";

const dx = new DataXAPI(); // reads DATAXAPI_API_KEY
const result = await dx.douyin.lives.search({ query: "东方甄选" });
console.log(result.data.items);
```

### 命令行

```bash
dataxapi call douyin.lives.search 'query=东方甄选'
```

## 常见问题

### 抖音直播搜索 API 多少钱？

$0.0200 一次。单次最高扣费 $0.0200。

### 什么情况下不收费？

出错和超时不收费。

### 一次返回多少条？怎么翻页？

每页 10 条。每页条数由平台决定，不收 limit。取下一页时把 page.next_cursor 作为 cursor 带上；游标有效期 1 小时。最后一页的 page.has_more 是 false。
