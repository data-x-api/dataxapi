# Channels share link object

The Channels share link object has 2 fields and is returned by 1 endpoint on WeChat Channels. A call costs $0.0200. It is a preview structure and may still change.

For machines: [channels_share_link schema](https://dataxapi.com/openapi.json#/components/schemas/channels_share_link), [openapi.json](https://dataxapi.com/openapi.json), [Object table (JSON)](https://api.dataxapi.com/v1/catalog/objects), [llms.txt](https://dataxapi.com/llms.txt)

A Channels share link opens a WeChat Channels (视频号) video in WeChat: a link starting with `weixin.qq.com/sph/`, for handing a video to a person. Each call makes a different link for the same video, and an older one still leads to it.

It is made from a video's numeric ID, the `id` a video list or a video gives; a link cannot be built from the ID by hand. The same link, given to the video detail endpoint as `url`, returns the video as Post.

## Fields

A field the platform cannot give is left out of the item and named in `meta.unavailable`. It is never filled with a guess or a zero.

| Field | Type | From view | Description |
| --- | --- | --- | --- |
| `id` | text | `compact` | The video's ID |
| `url` | link | `compact` | Share link that opens the video in WeChat |
