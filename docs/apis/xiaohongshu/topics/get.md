# Xiaohongshu (RedNote) topic detail API

Get one Xiaohongshu topic by its page ID: name, description, views, the discussion count the page shows, share link. One object a call; $0.0200 per call. Errors and timeouts are not charged.

- Endpoint: `GET https://api.dataxapi.com/v1/xiaohongshu/topics/get`
- ID: `xiaohongshu.topics.get`
- Also known as: rednote topic info, xhs hashtag page
- Price: $0.0200 / call
- Live status is not on this page, which is a snapshot. Read it with `GET https://api.dataxapi.com/v1/catalog/status`
- Returns: 1 object, one topic object
- Returns topic, a preview structure that may still change
- [Run it in the Playground](https://dataxapi.com/console/playground/?capability=xiaohongshu.topics.get&params=%7B%22id%22%3A%225eb2e2ffbd997100014327bc%22%7D)
- In Chinese: [小红书话题详情 API](https://dataxapi.com/zh/apis/xiaohongshu/topics/get/)

## Parameters

| Parameter | Type | required | Description |
| --- | --- | --- | --- |
| `id` | text | Yes | Topic page ID, 24 hexadecimal characters. Example: `5eb2e2ffbd997100014327bc`. |
| `view` | text |  | How much of each item to return. All three cost the same. Values: `compact`, `standard` (default), `full`. |
| `fields` | list of text |  | Return only these fields. Each by its path, such as `author.name`. |

## Returned fields

`data.item` is one topic object. Preview: the structure may change, announced beforehand.

Three views: `compact` (the most used fields, long text cut short), `standard` (the default: every standard field) and `full` (adds `ext`, the platform's own fields). A field is in the view named and in every larger one.

| Field | Type | Description | From view | This endpoint |
| --- | --- | --- | --- | --- |
| `id` | text | ID; pass it unchanged to the endpoints that get the topic and list the posts under it. | `compact` | Yes |
| `name` | text | Name of the topic. | `compact` | Yes |
| `url` | link | Link that opens the topic. | `compact` | Yes |
| `description` | text | What the topic says it is about; null when it says nothing. Long text: the compact view keeps the first 500 characters and says so in `warnings`. | `compact` | Yes |
| `metrics` | object | Topic counts. | `compact` | Yes |
| `metrics.views` | integer | Views of the topic. | `compact` | Yes |
| `metrics.posts` | integer | Posts under the topic. | `compact` | The platform has none |
| `ext.discussions` | integer | The discussion count the topic page shows (the number of people its share text says are discussing it). | `full` | Yes |
| `approximate` | list of object | Which numbers of this item are approximate or lower bounds; absent when all are exact. | `compact` | Yes |
| `approximate[].field` | text | Path of the field, such as metrics.views. | `compact` | Yes |
| `approximate[].kind` | text | Approximate, or a lower bound. Values: `approximate`, `lower_bound`. | `compact` | Yes |

A field with no value on an item is `null`. A field this endpoint cannot give is left out and listed in `meta.unavailable`.

Typical size of one item: `compact` 205 B, `standard` 205 B, `full` 236 B (measured on the response recorded 2026-10-13 03:28 UTC).

## If the object does not exist

The answer is 404 `not_found`. `charged` and `amount` in the body say what this one cost. `reason` says which: `not_found` (it does not exist) or `private_or_deleted`.
