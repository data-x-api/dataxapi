# WeChat Channels video detail API

Get one WeChat Channels video by its ID, a search result's export/ ID or its share link: description, author, time published, likes, comments, forwards, saves, and the video file's address with the key that decrypts it. One object a call; $0.0200 per call. Errors and timeouts are not charged.

- Endpoint: `GET https://api.dataxapi.com/v1/wechat_channels/videos/get`
- ID: `wechat_channels.videos.get`
- Also known as: channels post
- Price: $0.0200 / call
- Live status is not on this page, which is a snapshot. Read it with `GET https://api.dataxapi.com/v1/catalog/status`
- Returns: 1 object, one post object
- Returns the standard post object, the same on every platform
- [Run it in the Playground](https://dataxapi.com/console/playground/?capability=wechat_channels.videos.get&params=%7B%22id%22%3A%2214559898883113486609%22%7D)
- In Chinese: [微信视频号作品详情 API](https://dataxapi.com/zh/apis/wechat_channels/videos/get/)

## Parameters

| Parameter | Type | required | Description |
| --- | --- | --- | --- |
| `id` | text | give exactly one of `id`, `url`, `export_id` | The video's ID, a string of digits: the id a video list gives. Example: `14559898883113486609`. |
| `url` | text | give exactly one of `id`, `url`, `export_id` | The video's share link, starting with weixin.qq.com/sph/. Example: `https://weixin.qq.com/sph/ABgJVPnSSu`. Short link: `https://weixin.qq.com/sph/ABgJVPnSSu`. The link has to be opened to learn what it points at, so the result cannot be checked against it. |
| `export_id` | text | give exactly one of `id`, `url`, `export_id` | The id of a wechat_channels.videos.search result, starting with export/. It expires: use it soon after the search. The id returned is the video's numeric ID. Example: `export/UzFfBgAAxJeLPEsjEjWuk8zT4DCKThrNP5lzaPLJoEvz7FZtxw`. |
| `view` | text |  | How much of each item to return. All three cost the same. Values: `compact`, `standard` (default), `full`. |
| `fields` | list of text |  | Return only these fields. Each by its path, such as `author.name`. |

## Returned fields

`data.item` is one post object. Stable: fields are only ever added.

Three views: `compact` (the most used fields, long text cut short), `standard` (the default: every standard field) and `full` (adds `ext`, the platform's own fields). A field is in the view named and in every larger one.

| Field | Type | Description | From view | This endpoint |
| --- | --- | --- | --- | --- |
| `id` | text | ID; pass it unchanged to the get endpoint. | `compact` | Yes |
| `url` | link | Link that opens the post. | `compact` | The platform has none |
| `type` | text | Content format. Values: `video`, `image`, `text`, `article`. | `compact` | Yes |
| `title` | text | Title. | `compact` | The platform has none |
| `text` | text | Body text. Long text: the compact view keeps the first 500 characters and says so in `warnings`. | `compact` | Yes |
| `lang` | text | Language of the text. | `standard` | Not provided here |
| `published_at` | time | When it was published. | `compact` | Yes |
| `author` | object | Author. | `compact` | Yes |
| `author.id` | text | Author's account ID. | `compact` | Yes |
| `author.username` | text | Author's handle. | `compact` | The platform has none |
| `author.name` | text | Author's display name. | `compact` | Yes |
| `author.avatar_url` | link | Author's avatar. | `standard` | Not provided here |
| `author.verified` | yes/no | Whether the author is verified. | `standard` | Not provided here |
| `author.followers` | integer | Author's follower count. | `standard` | Not provided here |

| `hashtags` | list of text | Hashtags, without the #. | `standard` | Not provided here |
| `mentions` | list of object | Accounts mentioned in the text. | `standard` | Not provided here |
| `mentions[].id` | text | Account ID. | `standard` | Not provided here |
| `mentions[].username` | text | Handle. | `standard` | Not provided here |
| `mentions[].name` | text | Display name. | `standard` | Not provided here |
| `is_pinned` | yes/no | Whether the author pinned it. | `standard` | Not provided here |
| `post_id` | text | ID of the thread's root post when this is a reply; otherwise null. | `compact` | The platform has none |
| `parent_id` | text | ID of the item it replies to directly; otherwise null. | `compact` | The platform has none |
| `root_id` | text | ID of the first-level reply its thread hangs under. | `compact` | The platform has none |
| `ext.duration` | number | Length of the video, in seconds. | `full` | Yes |
| `ext.cover_url` | link | Cover of the video. | `full` | Yes |
| `ext.video_url` | link | Address of the video file; it expires. The file is encrypted: it plays once its first 128 KB are decrypted with the decode_key of the same answer. On this platform: WeChat Channels video files are encrypted, only their first 131072 bytes. Seed ISAAC64 with ext.decode_key, take each 64-bit output as 8 big-endian bytes for a key stream of 131072 bytes, and XOR it over the start of the file; the rest is left as it is, and the result is a playable MP4. Address and key change with every answer: use the pair from one answer. | `full` | Yes |
| `ext.decode_key` | text | Key that decrypts the file at video_url, good only for the address of the same answer. | `full` | Yes |
| `approximate` | list of object | Which numbers of this item are approximate or lower bounds; absent when all are exact. | `compact` | Yes |
| `approximate[].field` | text | Path of the field, such as metrics.views. | `compact` | Yes |
| `approximate[].kind` | text | Approximate, or a lower bound. Values: `approximate`, `lower_bound`. | `compact` | Yes |

A field with no value on an item is `null`. A field this endpoint cannot give is left out and listed in `meta.unavailable`.

Typical size of one item: `compact` 561 B, `standard` 561 B, `full` 2.0 KB (measured on the response recorded 2026-10-12 19:04 UTC).

## If the object does not exist

The answer is 404 `not_found`. `charged` and `amount` in the body say what this one cost. `reason` says which: `not_found` (it does not exist) or `private_or_deleted`.
