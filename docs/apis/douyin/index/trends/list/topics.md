# Douyin trend-index hot topics board API

This is the Douyin trend-index live hot topics API with `board=topics`. Get the live topic board or the fastest-rising topic board of Douyin's index tool, about 30 entries each: place, name, topic index, number of related videos, their plays and a category. The topic index is the platform's score of heat, not a count of searches. About 30 items a call, 50 at most; $0.0020 per call. Errors and timeouts are not charged; an empty result is charged $0.0020.

- Endpoint: `GET https://api.dataxapi.com/v1/douyin/index/trends/list`
- ID: `douyin.index.trends.list`
- A fixed option of: [Douyin trend-index live hot topics API](https://dataxapi.com/apis/douyin/index/trends/list/), `board=topics`
- Price: $0.0020 / call
- Live status is not on this page, which is a snapshot. Read it with `GET https://api.dataxapi.com/v1/catalog/status`
- Returns: up to 50 a page, everything in one answer, no paging
- Returns the standard trend object, the same on every platform
- [Run it in the Playground](https://dataxapi.com/console/playground/?capability=douyin.index.trends.list&params=%7B%22board%22%3A%22topics%22%7D)
- In Chinese: [抖音巨量算数实时热点榜 API](https://dataxapi.com/zh/apis/douyin/index/trends/list/topics/)

## Parameters

| Parameter | Type | required | Description |
| --- | --- | --- | --- |
| `board` | text |  | On this page it is fixed: `board=topics`. Which board: the hottest topics now, the fastest-rising topics. Values: `topics` (default), `rising`. Example: `topics`. |
| `view` | text |  | How much of each item to return. All three cost the same. Values: `compact`, `standard` (default), `full`. |
| `fields` | list of text |  | Return only these fields. Each by its path, such as `author.name`. |

## Returned fields

`data.items` is a list of trend objects. Stable: fields are only ever added.

Three views: `compact` (the most used fields, long text cut short), `standard` (the default: every standard field) and `full` (adds `ext`, the platform's own fields). A field is in the view named and in every larger one.

| Field | Type | Description | From view | This endpoint |
| --- | --- | --- | --- | --- |
| `id` | text | The platform's ID for the entry. | `compact` | The platform has none |
| `name` | text | Name of the entry. | `compact` | Yes |
| `rank` | integer | Position on the board, from 1; a pinned entry has none. | `compact` | Yes |
| `heat` | integer | The platform's heat score. On this platform: The topic index of Douyin's index tool. | `compact` | Yes |
| `ext.views` | integer | Total views of the related content. | `full` | Yes |
| `ext.videos` | integer | Number of related videos. | `full` | Yes |
| `ext.category` | text | The category the entry is filed under, in the platform's words. | `full` | Yes |
| `approximate` | list of object | Which numbers of this item are approximate or lower bounds; absent when all are exact. | `compact` | Yes |
| `approximate[].field` | text | Path of the field, such as metrics.views. | `compact` | Yes |
| `approximate[].kind` | text | Approximate, or a lower bound. Values: `approximate`, `lower_bound`. | `compact` | Yes |

A field with no value on an item is `null`. A field this endpoint cannot give is left out and listed in `meta.unavailable`.

Typical size of one item: `compact` 70 B, `standard` 70 B, `full` 128 B (measured on the response recorded 2026-10-12 21:56 UTC).

## Paging

About 30 items a page, 50 at most. The page size is the platform's; `limit` is not accepted.

Everything comes in one page; no cursor is issued.

Answers come from a shared snapshot refreshed every 10 minutes; `meta.cached` says so and `meta.fetched_at` is when it was taken.
