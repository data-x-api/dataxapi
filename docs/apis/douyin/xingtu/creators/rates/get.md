# Douyin Xingtu creator rate card API

Get what a Douyin creator charges on Xingtu for each kind of sponsored work, and how it is settled. One object a call; $0.0400 per call. Errors, timeouts and objects that do not exist are not charged.

- Endpoint: `GET https://api.dataxapi.com/v1/douyin/xingtu/creators/rates/get`
- ID: `douyin.xingtu.creators.rates.get`
- Also known as: creator rate card, influencer pricing, Douyin Xingtu creator rates
- Price: $0.0400 / call
- Live status is not on this page, which is a snapshot. Read it with `GET https://api.dataxapi.com/v1/catalog/status`
- Returns: 1 object, one creator rates object
- Returns creator rates, a preview structure that may still change
- [Run it in the Playground](https://dataxapi.com/console/playground/?capability=douyin.xingtu.creators.rates.get&params=%7B%22id%22%3A%226629656444889202692%22%7D)
- In Chinese: [抖音星图达人商业报价 API](https://dataxapi.com/zh/apis/douyin/xingtu/creators/rates/get/)

## Parameters

| Parameter | Type | required | Description |
| --- | --- | --- | --- |
| `id` | text | Yes | Xingtu creator ID. Example: `6629656444889202692`. |
| `view` | text |  | How much of each item to return. All three cost the same. Values: `compact`, `standard` (default), `full`. |
| `fields` | list of text |  | Return only these fields. Each by its path, such as `author.name`. |

## Returned fields

`data.item` is one creator rates object. Preview: the structure may change, announced beforehand.

Three views: `compact` (the most used fields, long text cut short), `standard` (the default: every standard field) and `full` (adds `ext`, the platform's own fields). A field is in the view named and in every larger one.

| Field | Type | Description | From view | This endpoint |
| --- | --- | --- | --- | --- |
| `creator_id` | text | Creator ID. | `compact` | Yes |
| `currency` | text | Currency of the rates. | `compact` | Yes |
| `rates` | list of object | Rate for each kind of sponsored work. | `compact` | Yes |
| `rates[].name` | text | Kind of work, in the platform's words. | `compact` | Yes |
| `rates[].amount` | amount | The rate; null when this kind has no fixed rate. | `compact` | Yes |
| `rates[].settlement` | text | How it is settled, in the platform's words. | `compact` | Yes |
| `rates[].open` | yes/no | Whether the creator takes this kind of work now. | `compact` | Yes |
| `approximate` | list of object | Which numbers of this item are approximate or lower bounds; absent when all are exact. | `compact` | Yes |
| `approximate[].field` | text | Path of the field, such as metrics.views. | `compact` | Yes |
| `approximate[].kind` | text | Approximate, or a lower bound. Values: `approximate`, `lower_bound`. | `compact` | Yes |

A field with no value on an item is `null`. A field this endpoint cannot give is left out and listed in `meta.unavailable`.

Typical size of one item: `compact` 593 B, `standard` 593 B, `full` 593 B (measured on the response recorded 2026-10-10 14:02 UTC).

## If the object does not exist

The answer is 404 `not_found` and nothing is charged. `reason` says which: `not_found` (it does not exist) or `private_or_deleted`.
